# 方舱显示名称

上海、深圳、北京、杭州及中心站点分别显示为上海方舱、深圳方舱、北京方舱、杭州方舱、中心方舱。界面中的管理栏目、数据归属和账号角色使用“方舱”“所属方舱”“方舱用户”等名称。跨域访问、逻辑域隔离仍保留其安全技术含义。

数据库内部的业务域模型、标识、编码、站点映射、接口字段及权限规则保持不变。拓扑图按站点使用相同的方舱显示名称。

上线时先备份 `collaboration_domain`，显式执行 `practice-server/src/main/resources/db/migration/V20261108_2__shelter_display_names.sql`。应用不会自动执行迁移。迁移仅替换匹配站点的原默认名称，保留管理员自定义名称，可重复执行。新数据库先执行原有建表及站点迁移，再执行此迁移。

历史任务、审批和审计快照、原始实验结果及导出文件保留创建时的名称，以保持记录原貌。当前页面中从方舱表读取的名称使用新称呼。
