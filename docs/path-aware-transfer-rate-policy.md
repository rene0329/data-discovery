# 按路径计算的受控传输限速

本策略用于异构带宽模拟。它根据近期逻辑拓扑测量计算 curl 的端到端每流限速，不是实际逐跳链路整形，也不是不限速网络的吞吐量预测。

## 保持的指标

不修改数据移动计时、文件完整性校验、任务结果、历史记录，以及集中式总数据移动耗时除以分布式总数据移动耗时的加速比计算口径。生产配置的目标区间仍为 1.30–1.69；区间内的速率比参考值仍按原规则取 1.612。目标区间是受控实验要求，不是任何文件大小、负载或资源回退下的无条件保证。

## 路径及计算方法

每条路径使用同一条最小时延路径的瓶颈带宽 B（Mbps）和累计时延 L（ms）。路径预算为 `P = B × 1000000 / 8 / (1 + L / 10)` 字节/秒。其中 10 ms 是固定的受控限速时延尺度，不是测得的 TCP 参数，不根据已产生的任务加速比调整。

对源节点 S，中心路径为 S 到配置的中心节点。分布式传输使用实际目标路径。计算中心限速时，分布式参考目标按源节点同站点优先、路径时延升序、带宽降序、节点编号升序选择可达的非中心计算节点。无近期完整测量时使用原人工规则，并记录回退原因。拓扑可达性排除不可调度节点；参考目标不代替实际计算资源调度。

令中心路径预算为 Pc，分布式路径预算为 Pd，参考速率比为 R，带宽安全系数为 s：

- 中心限速 `C = s / (1 / Pc + R / Pd)`。
- 分布式限速 `D = R × C`。
- 换算为整数 KiB/s，最低 1 KiB/s。

两条相关路径中任意一条的带宽提高或时延降低，都会使 C 和 D 增大，不再使用所有计算节点路径中的最低带宽。两个限速分别小于各自路径预算乘安全系数。对同一个源和同一个参考目标、同一次拓扑测量，理论速率比为 R；整数取整、curl 平均速率窗口、连接与校验成本、带宽竞争均可使实测耗时比偏离 R。调度因资源不足选择其他节点或两模式选择不同副本时也不保证该比值。相同物理路径按节点解析相同规则，不依据模式名称区别限速；本地路径没有可用网络带宽样本时回退人工配置。

## 运行与审计

自适应模式必须在管理 API 中启用，人工限速规则保留为回退。修改带版本号并写入配置历史；已创建 Job 的命令不变。日志记录配置版本、源/目标节点、实际路径瓶颈带宽、累计时延、分布式参考节点、目标速率比和最终限速。

正式前后对照应使用同一文件和输出校验，预先保存配置版本和测量；不得根据已看到的任务加速比反向调参，不应删除未达标结果。热敏存储迁移本身的成本单独记录，不将迁移后任务耗时误称为包含迁移成本的端到端加速。
